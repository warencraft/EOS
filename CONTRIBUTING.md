# CONTRIBUTING

Tento projekt sa riadi dokumentmi `EOS-000` až `EOS-005`.

## Pred pridaním zmeny

Over:

- či zmena patrí do aktuálnej fázy,
- či má správne ID,
- či neobsahuje neoverené strojárske hodnoty,
- či nezamieňa normy a odporúčania,
- či významná architektonická zmena vyžaduje ADR.

## Jazyk

Projektové dokumenty sa píšu po slovensky s diakritikou.

Programové identifikátory, JSON polia a názvy tried sa píšu po anglicky.

## Zdrojová klasifikácia

Technické tvrdenia musia používať klasifikácie:

- `N` - norma,
- `L` - literatúra,
- `P` - skúsenosť,
- `V` - overené výrobou.

## Definition of Done

Zmena je pripravená až vtedy, keď je dohľadateľná, zaradená do správneho modulu, nezdvojuje autoritatívne informácie a je v súlade s manifestom.
